Phishing Link Checker

Paste any link — from a text, email, QR code or social post — and Aegis dissects it the way a phishing kit builds it: host tricks, look-alike domains, hidden credentials and lure language, scored and explained in plain words.

Run the free check

Free, no sign-up. Nothing you paste is stored unless you create an account and save it yourself.

What it checks

  • Look-alike and homograph domains, including mixed-script Unicode hosts (a Cyrillic 'а' posing as Latin 'a')
  • Brand names hidden in paths, subdomains and userinfo ( paypal.com@evil-host style tricks)
  • Raw IP hosts, embedded username:password credentials, URL shorteners and open redirects
  • Abuse-prone free hosting and newly abused top-level domains
  • Double-encoded paths, zero-width characters and other normalisation tricks browsers resolve silently
  • Phishing and social-engineering lure phrases in the URL itself

How it works

The checker normalises the URL the same way a browser does (Unicode NFKC, zero-width stripping), then applies deterministic detectors — every point in the score traces to a named signal you can read. Scores combine into a 0–100 risk score with a verdict band from safe to malicious, plus a prevention step for anything it flags.

What the result means

  • Safe / likely safe — no meaningful signals; still stay alert if the message itself pressured you.
  • Caution / suspicious — one or more real phishing techniques are present; verify through the official app or site, typed by hand.
  • Malicious — multiple strong signals agree; do not open it and warn whoever sent it, their account may be compromised.

Frequently asked questions

Is this link checker really free?

Yes. Anonymous checks are free with a fair daily limit, and creating a free account raises it. The result of a check you run is never locked behind sign-up.

Do you visit the link to check it?

The basic check analyses the URL text only — it never fetches the page, so checking a link cannot infect you. The separate Redirect Tracer follows links server-side with an SSRF-guarded fetcher when you ask it to.

Can a checker guarantee a link is safe?

No tool can. Aegis explains the evidence it finds; a brand-new phishing domain with no tricks can score low. Treat a clean score as 'no known tricks', not a guarantee.
