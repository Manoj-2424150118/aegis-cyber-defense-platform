Secret Scanner

One pasted .env, one committed config, one debug log in a ticket — that is how most API keys leak. Paste text here first: the scanner finds provider keys, credential-bearing URLs and seed phrases, and shows you only masked fingerprints of what it found.

Run the free check

Free, no sign-up. Nothing you paste is stored unless you create an account and save it yourself.

What it checks

  • Provider formats: AWS access keys, GitHub tokens, Slack tokens, Stripe keys, SendGrid keys, Google API keys, private-key blocks
  • Database and service URLs with embedded passwords, and credentials in connection strings
  • Generic 'key = value' assignments with high-entropy values, filtered against placeholders and examples
  • JSON Web Tokens, payment card numbers (Luhn-verified), and crypto seed-phrase labels
  • Multiple independent leaks compound — scored with a noisy-OR model, not simple addition

How it works

Pattern and entropy analysis on the pasted text, in the request only. Output is masked by construction (first 4 + last 2 characters) and the redaction is enforced by tests: a raw secret can never appear in a result. Found something real? Rotate it — deletion is not enough, assume it was copied.

What the result means

  • Live keys (production Stripe/AWS/GitHub) are critical: revoke and rotate immediately, then audit their usage logs.
  • Test keys and examples still matter — they reveal where real ones live and how your configs are shaped.
  • A clean scan of one file is not a clean repo: scan history (git log) is where old secrets hide.

Frequently asked questions

Is it safe to paste a real secret here?

The scan runs in-request, stores nothing, and returns masked forms only. The safer habit still: scan before the text leaves your machine, and rotate anything real that you had to paste anywhere.

What should I do after finding a leaked key?

Revoke/rotate first, then remove it from the file and history, then check the provider's logs for use. Order matters — history edits do not un-leak a key.

Does it scan my whole repository?

This tool checks pasted text (up to 100 KB). For repos, pair it with pre-commit hooks like gitleaks; this scanner is the fast check before you paste, post or commit.
