Website Safety Audit

For site owners and the cautious alike: enter a URL and get a graded audit of the security configuration browsers actually enforce — HTTPS, HSTS, CSP, cookie flags and the headers that decide how exploitable common bugs are.

Run the free check

Free, no sign-up. Nothing you paste is stored unless you create an account and save it yourself.

What it checks

  • HTTPS availability and redirect enforcement, HSTS presence and strength
  • Content-Security-Policy, X-Frame-Options / frame-ancestors, nosniff, Referrer-Policy, Permissions-Policy
  • Cookie flags: Secure, HttpOnly, SameSite on session-like cookies
  • Mixed content and server/version disclosure headers
  • Each missing control with the exact header to add

How it works

Aegis fetches the page headers with its guarded fetcher and grades against the same checklist it applies to itself (this site scores itself with the same engine). Findings are configuration facts, each with a copy-pasteable fix.

What the result means

  • A-grade configuration does not mean the application has no bugs — it means the browser-level safety nets are all in place.
  • Missing CSP is the most common gap; it is also the one that turns a small XSS into a full account takeover.
  • Cookie flags are one-line fixes with outsized effect on session theft.

Frequently asked questions

Can I audit a site I don't own?

Yes — this reads only the public response headers any browser receives. It is the same information security scanners and the sites' own users can see.

Why does this site grade itself?

Aegis eats its own cooking: the platform serves the headers this audit recommends, under a strict CSP with no inline scripts.

What grade should I aim for?

A or A− is achievable for most sites in an afternoon of header work; the audit lists fixes in impact order.
