Password Lab

Two questions decide whether a password survives: could a human pattern-guesser crack it, and has it already leaked? The Lab answers both — strength with real pattern detection, exposure with a privacy-preserving breach lookup.

Run the free check

Free, no sign-up. Nothing you paste is stored unless you create an account and save it yourself.

What it checks

  • Keyboard walks (qwerty, 1qaz2wsx), sequences, repeated chunks and years — the patterns cracking tools try first
  • Leetspeak dictionary words (P@ssw0rd is still 'password')
  • True entropy from character pools and length, not just 'has a symbol' theatre
  • Breach exposure via Have I Been Pwned's k-anonymity API — only the first 5 characters of the SHA-1 hash leave your browser's request
  • A generator for passphrases and random passwords that pass these same checks

How it works

Strength is scored on structure, not superstition: pattern findings cap the score the way real cracking order would. The breach check uses the k-anonymity model — your password and its full hash are never sent or stored.

What the result means

  • Length beats complexity games: a 5-word passphrase outlasts P@ssw0rd2024 by orders of magnitude.
  • 'Breached' means the password exists in public leak corpora — anyone can try it against your accounts. Change it everywhere it was reused.
  • Every account needs a unique password; a password manager's vault (like the one here) makes that practical.

Frequently asked questions

Is it safe to type my password here?

The strength check runs against the pasted text only and stores nothing; the breach check sends only a 5-character hash prefix. Still, good practice: test a similar password, not the live one, on any site — including this one.

How long should a password be?

At least 14–16 characters for important accounts, or a 5+ word passphrase. Length is the cheapest security there is.

What is credential stuffing?

Attackers replay leaked email/password pairs against other sites automatically. Unique passwords per site make a leak survivable.
